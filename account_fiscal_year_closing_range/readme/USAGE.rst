**Account Range Wizard**

If you want to generate multiple mapping records at once for a specific range of accounts:

#. Go to the **Accounts mapping** section in a Fiscal Year Closing configuration or template.
#. Click the **"Generate Range"** button (magic icon) located above the mapping list.
#. In the wizard:
    * Set the **Start Account Code** and **End Account Code**.
    * Enter the **Destination Account Code** (e.g., ``3.1.01.001``).
    * Optional: Define a **Mapping Name Prefix** to identify these lines easily.
#. Click **"Generate Mappings"**.
#. The wizard will find all accounts in the range and create an individual mapping line for each one, using the provided destination code.
